# 10구 승부: 나이트 홈런 더비
XR콘텐츠응용 중간과제 – Unity 패키지

## 다운로드
오른쪽 Releases → XR_MidtermProject_202571231.unitypackage

## 실행 방법
1. Unity 2021.3.44f1로 새 3D 프로젝트를 만듭니다.
2. Assets → Import Package → Custom Package... 로 위 파일을 가져옵니다 (All → Import).
3. Assets/1st.unity 씬을 열고 Play를 누릅니다.

## 조작
- 덕아웃 → 타석: WASD 이동, Space 점프
- 타석: 마우스로 조준 원 이동, 클릭으로 스윙 (10구)
